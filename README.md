# Alfredo Bank Application

A secure, robust, and user-friendly banking application designed to handle standard financial transactions, user authentication, and account management. 

##  Features

### User Management & Security
* **Secure Authentication:** User login and registration backed by secure password hashing.

### Core Banking Operations
* **Account Dashboard.
* **Deposits & Withdrawals:** Securely fund your account or withdraw money with instant balance updates.
